What is ApiSynIQ?

ApiSynIQ is an open-source framework that sits as a conversational layer in front of your APIs. Instead of building complex frontend forms for every endpoint, your users simply speak or type what they want — and ApiSynIQ figures out the intent, constructs the correct request payload, calls the right endpoint, and returns a human-readable response.

Say "Book me a ticket to Mumbai for tomorrow" or type "Update my shipping address to…" — ApiSynIQ handles the rest. It works with voice, text, HTTP, and WebSocket out of the box.

Architecture

A user query travels through four purpose-built layers, each chosen for what it does best.

Fig 1 — ApiSynIQ Production Grade Architecture

Go
Layer 1

GO Gateway — Handle Everything, Drop Nothing

Every request — voice or text, HTTP or WebSocket — lands at the GO Gateway first. Go was chosen deliberately: its goroutine model makes concurrent request handling nearly effortless, making it the ideal reliable front door for high-throughput workloads.

  • net/http — handles all standard HTTP requests with zero overhead
  • gorilla/websocket — maintains persistent, streaming WebSocket connections so AI tokens flow to the client in real time, as they're generated

Once a request is accepted, it's dispatched to the AI Orchestrator over gRPC.

Python
Layer 2

AI Orchestrator — The Brain

Written in Python — when it comes to AI tooling, nothing else comes close. This is where all the intelligence lives: routing, reasoning, context management, and tool execution.

  • Route user requests to the right AI model
  • Reason about which API endpoint best satisfies the user's intent
  • Pull relevant context and feed it to the model
  • Persist conversation history to the database
  • Manage LangChain and LangGraph agent logic
  • Define tools and wire them to deep agents and subagents
  • Transcribe voice → text and synthesize text → voice
  • Convert raw JSON schemas into Pydantic models for clean, typed API definitions

Java
Layer 3

API Resolver — The Memory

Written in Java, which brings a mature, battle-tested ecosystem for database-heavy workloads. This service is the RAG engine of ApiSynIQ — it stores every API's input and output descriptions as vector embeddings in pgvector (PostgreSQL), and when the orchestrator needs to find the right endpoint, it runs a semantic similarity search — not a brittle keyword lookup, but genuine meaning-based retrieval.

⟷ Relational mappings between API parameters and natural language descriptions
{ } Structured storage for every JSON schema an API accepts
⚙ All CRUD operations for the SDK
↑ Backend for SDK updates triggered through the UI
Java SDK
Layer 4

Java Agent SDK — The Connector

The Java Agent is an annotation-based SDK that lets you describe your API endpoints, DTOs, and parameters in plain language — right inside your existing Java code. No separate config files, no external schema management. Just annotate, and ApiSynIQ knows everything it needs to route, fill, and call your APIs intelligently.

Currently available for Java. Support for more languages is on the roadmap.

Annotation Details

@AIExposeController

Placed on top of a controller class. Gives ApiSynIQ a complete picture of all the endpoints in the class — what they collectively do and why they exist.

Parameters:  name   A short identifier for the controller.    description   What all the endpoints in this controller are for.

@AIExposeDto

Placed on a DTO class. Describes the object so the AI knows what it's filling — whether it's a request body, a general input parameter, or a nested object.

Parameters:  name   Identifier for the DTO.    description   What this object represents.    example   A sample filled object for context.

@AIExposeEpHttp

The richest annotation — placed on individual endpoint methods. Fully describes an endpoint: what it does, how to call it, when to use it, and what it returns. The inputDescription and returnDescription fields power the semantic search in the API Resolver.

Parameters:  name · tags · example · pathParameters · requestParameters · headers · variables · autoExecute · inputDescription · returnDescription

@Describe

A versatile annotation that can be placed on any variable — DTO fields, query parameters, path parameters, and more. Provides fine-grained context on what each individual field is, what it accepts, and how it behaves.

Parameters:  name · description · dataType · defaultValue · options · autoExecute · example

Annotation Example

Java 
@AIExposeController(
    name = "BookingController",
    description = "Handles all ticket booking operations including creation, cancellation, and status checks."
)
@RestController
@RequestMapping("/api/bookings")
public class BookingController {

    @AIExposeEpHttp(
        name = "CreateBooking",
        tags = {"booking", "create"},
        inputDescription = "Creates a new ticket booking for a user given destination, date, and seat preference.",
        returnDescription = "Returns the booking confirmation ID and seat details.",
        example = "Book a window seat to Mumbai for tomorrow morning."
    )
    @PostMapping("/create")
    public ResponseEntity<BookingResponse> createBooking(
        @RequestBody @AIExposeDto(
            name = "BookingRequest",
            description = "Request body for creating a new booking.",
            example = "{\"destination\": \"Mumbai\", \"date\": \"2025-04-01\", \"seat\": \"window\"}"
        ) BookingRequest request) {
        // ... booking logic
    }
}

// DTO with @Describe on each field
public class BookingRequest {

    @Describe(
        name = "destination",
        description = "The city or station the user wants to travel to.",
        dataType = "String",
        example = "Mumbai"
    )
    private String destination;

    @Describe(
        name = "date",
        description = "Travel date in YYYY-MM-DD format.",
        dataType = "String",
        example = "2025-04-01"
    )
    private String date;

    @Describe(
        name = "seat",
        description = "Preferred seat type.",
        dataType = "String",
        options = {"window", "aisle", "middle"},
        defaultValue = "aisle"
    )
    private String seat;
}
